# Timelines

Periods and events as a vertical list; sections become headers.

```mermaid
timeline
  title History of the web
  section Early days
  1991 : WWW
  2004 : Web 2.0 : Social media
  section Modern
  2023 : LLMs everywhere
```

```text
── History of the web ──
Early days
1991 ─ WWW
2004 ─ Web 2.0
     ─ Social media
Modern
2023 ─ LLMs everywhere
```
